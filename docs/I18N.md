# 国际化（i18n）

库：i18next 27 + react-i18next 18。代码在 `apps/demo/src/lib/i18n/`。支持语言：`zh-CN`（默认，回退语言）、`en`。

| 文件 | 作用 |
| --- | --- |
| `index.ts` | 创建实例，初始语言取自本地存储，并同步 `<html lang>` |
| `language.ts` | `languages`、`Language`、`getStoredLanguage`、`setStoredLanguage`（键 `marismoon-language`）、`applyDocumentLanguage` |
| `resources.ts` | 命名空间 `translation`：点号键，用于页面标题与副标题 |
| `ui-en.ts` | 命名空间 `ui`：以中文原文为键的英文对照，用于外壳、导航、命令面板、共享组件文案 |
| `ui-en-features.ts` | 同一命名空间：overview、bills、copilot、基础页面及其示例数据的英文对照 |
| `use-ui-text.ts` | `useUiText()` → `tl(中文原文, 变量?)` 与 `tl.parts("标题 · 说明")`；`tl` 随语言变化，可放进 `useMemo` 依赖 |
| `UiTrans.tsx` | 含行内元素（如 `<b>`）的句子：`<UiTrans source="如果 <0>{{email}}</0> …" components={[<b />]} values={{ email }} />` |
| `UiLabelsBridge.tsx` | 把翻译后的文案经 `UiLabelsProvider` 提供给 `@marismoon/ui` 的共享组件 |
| `ShellLabelsBridge.tsx` | 将外壳固定文案映射为 `ShellLabels`，向外壳提供当前语言、选项和切换回调 |
| `index.test.ts`、`coverage.test.ts` | 页面键与导航标签、语言存取、源码中所有 `tl("…")` / `UiTrans` 字面量都必须有英文 |

切换入口：页头 `LanguageControl`（`@marismoon/shell` 导出，在 `WorkspaceControls` 内）按选项顺序循环。Demo 在 `ShellLabelsBridge.tsx` 中写入 `marismoon-language`、同步文档语言并切换译文，刷新后保留。

## 两种写法，何时用哪种

1. **页面标题 / 副标题 / 多处复用的文案** → 点号键 + `t()`：
   1. 在 `resources.ts` 的 `zh-CN.translation` 与 `en.translation` 同时加同名键；
   2. 页面配置里写 `titleKey` / `descriptionKey`（`app/workspace-pages.tsx`）；
   3. 组件里 `const { t } = useTranslation()`，`t("模块.键")`。
2. **导航标签、按钮文字、aria-label、提示等短文案** → `tl("中文原文")`：
   1. 组件里 `const tl = useUiText()`；
   2. 文案写 `{tl("全部数据")}` / `aria-label={tl("工作区目录")}`；
   3. 在 `ui-en.ts` 加 `"全部数据": "All data"`。
   - `app/workspace-modules.ts` 与页面 `breadcrumbs` 保留中文原文。Demo 在 `app/use-workspace-navigation.tsx` 构造导航 Schema 时翻译菜单，在 `app/router.tsx` 渲染路由时翻译面包屑，再传给外壳。

## 新增语言（例：日语 `ja`）

1. `language.ts` 的 `languages` 加 `ja: "日本語"`。
2. `resources.ts` 加 `ja: { translation: { … } }`（键与 `zh-CN` 一致）。
3. `ui-en.ts` 同级新增 `ui-ja.ts`，并在 `index.ts` 的 `resources` 里挂 `ja: { ...resources.ja, ui: uiJa }`。
4. `LanguageControl` 按 `languages` 的顺序循环，无需改动；若语言超过 3 种，建议改成下拉菜单。
5. 为 `index.test.ts` 的覆盖断言加入新语言。

## 变量、数据与共享组件

- **变量**：`tl("共 {{count}} 条", { count })`；模板字符串不要直接拼接中文，改成占位符。
- **数据保持中文原文，在渲染处翻译**：模块级常量和 Mock 数据保留原文，Demo 渲染时用 `tl(item.label)` 翻译；形如「账号 · 环境」的组合用 `tl.parts(...)`（按 ` · ` 拆开逐段翻译，缺失的段落原样显示）。
- **共享组件**（`packages/ui`）不依赖 i18next：固定文案放在 `packages/ui/src/lib/ui-labels.ts` 的 `UiLabels`（带中文默认值），应用在 `UiLabelsBridge` 里提供翻译。新增共享组件的固定文案时，先加到 `UiLabels` 与 `ui-en.ts`，再在组件里 `useUiLabels()` 读取。
- **Copilot 回复**：`getCopilotReply(question, pending, tl)` 接收翻译函数，不传则输出中文（单测依赖这一点）。

## 已覆盖与未覆盖

- **已覆盖（中英文）**：页面标题与副标题、面包屑、第一列与第二列导航、命令面板、外壳 aria-label、页头控件、表格底栏与分页、Dialog 关闭文案、overview、bills（含抽屉）、copilot、基础页面（`settings/base-pages`）。`e2e/i18n.spec.ts` 在英文下扫描这些页面，不允许残留中文。
- **未覆盖**：「系统设置」下的组件预览、动效演示与官方 shadcn 示例（`features/settings/examples`、`*-demos.tsx`、`MotionPage.tsx` 等）仍是中文写死，它们是开发期对照页面，正式开发时删除；Mock 数据里的企业主体名、人名（如 `星河科技…`、`陈**`）有少量英文对照，其余保持原样。
- 金额、日期格式化在 `@marismoon/ui/lib/format`（固定 `zh-CN` 习惯），多语言时再按语言参数化。
